\# Меню-раскладка



Система расчёта продуктов для школьного питания. Помогает завхозу вести справочник продуктов, составлять меню, рассчитывать потребность в продуктах и формировать накладную для заказа.



\## Проблема



В большинстве школ меню-раскладка считается вручную в Excel или на бумаге. Это долго, ошибкоопасно и неудобно. Приложение автоматизирует рутину.



\## Что уже умеет



\- 📦 \*\*Справочник продуктов\*\* — добавление, редактирование, удаление, количество, примечания.

\- ⚙️ \*\*Настройки школы\*\* — название, адрес, ИНН, поставщик, подписант. Заполняются один раз и автоматически попадают в накладную.

\- 📄 \*\*Экспорт накладной в PDF\*\* — с шапкой, таблицей, подписью и местом печати.

\- 📊 \*\*Экспорт в CSV\*\* — для Excel.



\## В разработке



\- 🍲 Справочник блюд с технологическими картами.

\- 📅 Составление меню на день/неделю.

\- 🧮 Автоматический расчёт заявки на продукты.

\- 📱 Экспорт накладной картинкой (PNG) для мессенджеров.



\## Стек



\- Python 3.14

\- Streamlit — интерфейс

\- SQLite — база данных

\- pandas — работа с данными

\- fpdf2 — генерация PDF
